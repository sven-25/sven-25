## About Me

I'm a self-taught developer who ended up here through curiosity more than credentials. Right now I contribute to a handful of open-source projects that I actually use — small tools, downloaders, CLI utilities. Nothing flashy; just things that make my daily setup work a little smoother.

**Warm, earthy, old-school.** My philosophy is simple: read more code than you write, ship small, and be honest about what you don't know yet.

Currently interested in c, bash, and figuring out how vim actually works under the hood.
